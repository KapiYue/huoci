# 账号与学习数据只读审计规格

## Requirement: 审计不得改变生产或用户状态

审计工具和人工核验必须使用可证明的只读通道，且不得触发认证、写入、迁移、关联、解绑、会话刷新或测试账号创建。

### Scenario: 只读通道不可用

- **WHEN** 无法确认目标访问通道为只读，或访问需要写权限
- **THEN** 审计停止该项并记录阻塞原因
- **AND THEN** 不以执行写入、创建临时账号或调用可写 RPC 作为替代

## Requirement: 审计输出必须脱敏且可区分证据来源

审计报告只可包含元数据、聚合数量、布尔结果、校验摘要、版本和风险结论；每条结论必须标明证据类型与证据状态。

### Scenario: 发现需要具体用户记录才能得出结论

- **WHEN** 聚合与元数据不足以判断某项存量风险
- **THEN** 报告将该项标为未知或需进一步授权
- **AND THEN** 不输出或保存用户身份、学习内容、认证凭据或原始查询结果

## Requirement: 审计必须按 V1 契约识别差异而不预设修复

审计应覆盖独立身份、可撤销授权共享、内容/行为归属、事件幂等、进度可重算和解除关联后的访问收敛。

### Scenario: 发现旧模型行为

- **WHEN** 证据显示关联会迁移身份、合并数据或解绑复制数据
- **THEN** 报告将其标为与 V1 契约的差异和存量风险
- **AND THEN** 不在本 change 中修改数据、代码或迁移来修复
