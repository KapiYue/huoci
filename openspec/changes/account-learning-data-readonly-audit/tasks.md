# 实施任务

> 执行阶段仅处理第一个未完成任务项。每一项均为只读；任何生产访问不可用或无法保证只读时，停止并报告，不改用写入方式。

## 1. 审计准备与本地证据清单

- [ ] 1.1 对照 V1 三份产品契约，列出需要核实的身份、关系、内容、行为、进度、会话和授权收敛问题；标出可由本地源码确认与必须依赖生产只读元数据确认的部分。

## 2. 生产元数据与聚合核验

- [ ] 2.1 在受控只读通道核实已应用迁移、相关表/列、主外键、唯一约束、索引、RLS 策略和 RPC 权限；仅保存元数据、计数和摘要。
- [ ] 2.2 对身份映射、关联关系、学习表及旧模型批次/审计表执行脱敏聚合完整性检查，识别重复、归属不一致、孤立引用和无法解释的存量风险；不查询用户内容或身份行。

## 3. 会话与客户端路径核验

- [ ] 3.1 只读审阅已发布对应版本的网关/小程序路径及本地缓存、离线队列逻辑，形成 W/C 会话主体、访问边界和解绑收敛的证据矩阵；不能证明线上版本一致时标为未知。

## 4. 报告与下一项建议

- [ ] 4.1 汇总脱敏审计报告：逐项标注证据等级、V1 差异、风险与未知项，并提出后续 V1 改造 change 的候选范围；不创建迁移方案，不实施改造。
