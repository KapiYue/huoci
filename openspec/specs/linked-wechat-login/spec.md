# 微信与词鲸账号关系 V1 Specification

> 本规格已按用户验收后的 V1 产品目标同步。`linked-wechat-login-session` 的实现代码与测试属于旧模型历史记录，归档后不得视为本规格已经实现。

## ADDED Requirements

### Requirement: 微信与词鲸身份保持独立

系统 MUST 将微信账号 W 与词鲸邮箱账号 C 作为两个独立身份保存。关联 MUST 只建立可撤销的授权关系，不得把 W 转换为 C、迁移双方原始数据或因普通邮箱登录自动建立关联。

#### Scenario: 未关联的两个账号独立使用

- **GIVEN** 微信身份映射到 W，且不存在有效关联关系
- **WHEN** 用户分别使用微信入口和词鲸邮箱入口
- **THEN** 微信入口访问 W 的独立数据，邮箱入口访问 C 的独立数据
- **AND** 任一入口不得因登录行为改变另一账号的身份或数据归属

### Requirement: 关联必须经过双重验证和主动确认

系统 MUST 要求用户从已登录的 W 主动发起关联，验证 W 与 C 的控制权并明确确认授权范围。首版一个 W 最多关联一个 C，一个 C 最多关联一个 W。

#### Scenario: 关联验证未完成

- **WHEN** 用户未完成任一身份验证或未勾选确认
- **THEN** 系统不得创建关联关系或开放共享内容
- **AND** W 仍可独立使用

#### Scenario: 关联成功

- **WHEN** 用户完成双重验证并确认
- **THEN** 系统创建 W 与 C 的可撤销授权关系
- **AND** 双方原始内容和学习事件归属保持不变

### Requirement: 关联期间按授权形成统一学习进度

系统 MUST 在当前授权范围内，根据唯一、有效且词条身份一致的学习事件计算统一学习进度。统一进度 MUST 是可重算视图，不得作为双方原始事件互相覆盖。

#### Scenario: 两端学习同一合法词条

- **GIVEN** W 与 C 对同一规范词条产生不同的有效学习事件
- **WHEN** 关联授权有效
- **THEN** 统一视图可以纳入双方事件
- **AND** 网络重试、离线补发或重新关联不得重复计数

#### Scenario: 词条身份不一致

- **GIVEN** 两条记录仅拼写相同但词性、含义或规范词条不同
- **WHEN** 系统计算统一进度
- **THEN** 系统不得直接合算两条记录

### Requirement: 解除关联回到微信独立状态

解除关联 MUST 只撤销跨端授权。W MUST 保持登录并回到已登录未关联的正常产品页面，不得跳转到退出登录或首启引导。C 的原始数据和学习历史 MUST 保留；C 专属内容 MUST 立即停止展示给 W。

#### Scenario: 解除关联成功

- **GIVEN** W 与 C 存在有效关联
- **WHEN** 用户确认解除关联且服务端完成处理
- **THEN** 关联关系和共享访问权限失效
- **AND** W 仍保持有效登录并显示独立视图
- **AND** W 与 C 不删除、复制或覆盖原始学习事件

#### Scenario: 解除关联结果未知或失败

- **WHEN** 服务端未确认解除关联成功
- **THEN** 客户端不得提前显示解除成功
- **AND** 系统必须核实关系与授权状态，避免界面和服务端状态分裂

### Requirement: 重新关联按当前授权重新计算

重新关联原 C MUST 重新完成身份验证，并按当前授权重新计算合法历史进度，不得重复创建历史事件。改关联 C002 时，系统 MUST 隔离 C001 的专属内容、来源和历史。

#### Scenario: 重新关联原 C

- **WHEN** W 解除关联后重新验证并关联原 C
- **THEN** 系统恢复当前授权范围内的合法内容访问与统一进度
- **AND** 解绑期间 W 自有且合法匹配的新增事件可以参与计算

#### Scenario: 改关联其他 C

- **WHEN** W 与 C002 建立关联
- **THEN** C001 的专属内容、来源元数据和未授权历史不得展示或带入 C002

### Requirement: 共享权限在跨设备和离线场景收敛

解除关联后，所有设备的共享会话、缓存访问和离线同步 MUST 按服务端关系状态收敛。无法可靠证明产生时授权有效的 C 专属离线操作 MUST 暂停同步，不得无条件写入或开放内容。

#### Scenario: 另一设备持有旧会话

- **WHEN** W 在设备 A 解除关联，设备 B 使用旧缓存或共享会话请求 C 内容
- **THEN** 服务端拒绝无效授权，客户端不得继续展示受限内容

### Requirement: 存量数据处理前必须只读审计

系统 MUST 在处理旧模型可能产生的合并、复制或重复数据前，审计真实身份主键、外键、事件时间线、唯一约束、RLS 和权限路径。未经单独的影响评估与授权，不得删除、迁移或覆盖线上账号与学习数据。
