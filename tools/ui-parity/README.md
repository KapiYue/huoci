# ui-parity · 九屏还原对照

```bash
npm run parity          # 终端表格 + 写 report.md；有 🔴 就 exit 1
npm run parity -- --soft  # 同上，但恒 exit 0（只想看报告时用）
```

## 它回答的那一个问题

`dev-todo.md` 的 MVP-1 第 ① 条腿是「逐屏对照 `design.md` §5：**结构 / 文案 / 状态 / 交互次序**
四项全中」。这件事以前只能靠人逐屏看，看漏了不会有人知道。这个工具把其中**能被判定的
那一部分**变成一条命令。

## 权威关系（整个工具的地基）

| 这一边 | 谁说了算 | 冲突时 |
|---|---|---|
| 功能 / 结构 / 文案 | **`docs/design.md` §5** | 原型跟它冲突 → 改原型，实现不要抄原型 |
| 视觉 / 效果 / 布局 / 配色 | **`docs/prototype/`** | 实现跟它不一致 → 改实现 |

所以每一屏都是**三方比对**，不是两方：规格 ↔ 原型 ↔ 小程序，三条边各自出结论。

## 四种结论

| | 含义 | 该做什么 |
|---|---|---|
| 🔴 | 实现违反了 `design.md` §5 | **改实现**。这是 exit 1 的唯一来源 |
| 🟡 | 原型违反了 `design.md` §5 | **改原型**。实现照着抄就会一起错 |
| 🎨 | 原型里有、实现里没有的文案 | **逐条判断**：是 UI 还原漏了，还是原型多画了（多半是后者，因为原型比规格旧） |
| 📎 | 注释里的 `§编号` 在 `design.md` 里不存在 | 改注释。09-02 三份旧文档合并时全文重编号，注释不会自己跟着变 |

🎨 一栏**天然不会归零**，也不该追求归零 —— 它是一张「原型比规格多画了什么」的清单，
用来防止「实现悄悄跟着原型跑偏」和「UI 细节悄悄丢了」这两件相反的事。

## 文件

| | |
|---|---|
| `spec.mjs` | **判据本体**。`design.md` §5 的机器可读转写。改它的唯一理由是 §5 改了 —— 不要为了让报告变绿改判据 |
| `extract.mjs` | 从 `.wxml` / `.tsx` / `.ts` / `.json` 里抽「用户看得见的文案」。正则不是 AST：判据只需要「出现 / 不出现」，且宁可多抽不可漏抽 |
| `check.mjs` | 执行体，产出 findings |
| `refs.mjs` | `§编号` 体检（📎） |
| `palette.mjs` | Tailwind 默认调色板，用来把 `tokens.wxss` 的每个 hex 追溯回原型 |
| `cli.mjs` | 渲染 + 退出码 |
| `mascot-check.html` | 吉祥物的**逐像素**核对稿，见下 |
| `report.md` | 生成物，**不要手改** |

## 这个工具测不到的

它读源码，不跑渲染，所以下面这些只能靠眼睛，`dev-todo.md` T8 里那条「开发者工具真机跑一遍」不能省：

- 间距 / 字号 / 圆角的实际观感（只能校配色令牌，校不了版式）
- 动效、转场、按压反馈
- 深色模式的实际效果
- 「交互次序」四项判据里的这一项 —— 现在只能校到「按钮在不在」，校不到「点了之后去哪」

`mascot-check.html` 是对第一条的局部补丁：把 `mascot.wxss` 的 rpx 按 1rpx = 0.5px 换算成
等价 HTML，与原型的 SVG 并排放，浏览器里直接打开就能看出形状差。这个办法可以照搬到别的
纯 CSS 组件上，但对整页布局不划算 —— 整页去开发者工具里看更快。
